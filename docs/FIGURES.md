## Background experiment

The reference is epoch 37 (best validation) of the 40-epoch `background_v1_20260920` run. The checkpoint SHA-256 and portable training settings are in `results/background-training.json`. Figures are rendered from the same examples/predictions using `background_plots.py` and `apply_background.py`; numeric summaries are in `results/background.json` and `results/background-fits.json`.

| Figure | Source and selection |
|---|---|
| `background-synthetic.png` | `heldout_examples.png`: first encountered zero-background, nonzero broad-signal and other nonzero example in each held-out split, in dataset order; not selected by prediction quality. Separate labelled spectrum/background scales within rows; true and estimated backgrounds share their scale. |
| `background-fit-examples.png` | `fit_examples.png`: first noise repeat of each signal case with hump background. Shared scale within rows. These are spectrum examples, not fitted EDC curves. |
| `background-experimental.png` | `experimental/comparison.png`: same corrected `mos2_2_074.sp2` acquisition as the denoising preview; original/resampled input and signed subtraction share a scale; the background has a separate labelled scale. No experimental ground truth. |

Background plots show negative corrected values as black; exported arrays preserve them. Curated figures contain no raw acquisition attachment or labbook scans. Exact experimental reproduction requires the private source acquisition.

### Balanced-background v2 comparison

`background-v2-test-v1.png` and `background-v2-test-v2.png` show the same first test example in each of seven v2 regimes, using the old and new checkpoints respectively. Generated by `compare_background.py` through `background_plots.py`; seed 42, dataset indices 0–6. No prediction-quality selection. The new model is epoch 36 of `background_v2_20260920`; both checkpoint hashes and run settings are in `results/background-v2-training.json`. True/estimated backgrounds share a scale within each row; spectra share a separate scale. Scales may differ between the two model figures.

`background-v2-experimental-five.png` is the background-v2 preview of corrected SP2 acquisitions `mos2_2_061`, `065`, `069`, `073` and `077`. Selection uses evenly spaced positions in the sorted 17-file sequence, before inference, excluding the frequently shown 074. Original acquisition, resampled input and signed corrected spectrum share a linear scale per row; the background has its own linear colorbar. Displayed negative values are black but preserved in numerical outputs. Portable fractions and checkpoint hash are in `results/background-v2-experimental.json`; no raw arrays, acquisition headers or labbook scans are distributed.
